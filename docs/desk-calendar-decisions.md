# 桌历功能决策记录（逐项与用户确认后的定稿，2026-09-03）

> 本文档记录「桌面日历」功能/设计的**所有已确认决策**，以及待确认项（见文末「待确认」）。所有题均以选择题形式向用户逐一确认过；确认结果在此落盘，避免返工/忘。

## 一、窗口行为（已确认）
- **贴底层级**：目标层级 = **图标之下、壁纸之上**（与 DesktopCal 一致）。实现：向 `Progman` 发 `WM_SPAWN_WORKERW(0x052C)` 生成壁纸 `WorkerW`，用 `SetParent` 把桌历窗口挂到该 WorkerW（改 `WS_CHILD`、去 `WS_POPUP`；**绝不能加 `WS_EX_TRANSPARENT`**，否则整窗点击穿透、无法交互）；找不到 WorkerW 时回退 Progman。**去掉 setAlwaysOnTop 置顶**。`desktopPinning.pinWindowToDesktopBottom` 首选 WorkerW 嵌入，失败回退（Progman + `GW_HWNDNEXT`）。
- **格子布局自适应**：完全仿 DeskToDo —— 格子随窗口均分拉伸、**无整体滚动条**；某天任务多时**只在格内滚**（透明隐藏滚动条），不撑宽窗口。
- **位置记忆**：仿 DeskToDo —— 按「显示器组合签名」分别记忆窗口位置/尺寸/列宽，换屏恢复；候选位置不在任何屏幕内则回退默认（resize 兜底）。
- **视图**：月 + 周 + 日 三视图（与主界面一致）；月/周/日都显示 课程/考试/截止/待办（与主界面 schedule-event 一致）。

## 二、格子内容与事件（已确认）
- **事件线样式**：跟随主界面——色条/圆点 两档（主界面已是 bar|dot 切换）。
- **双击某天格子** → 弹【新增事件窗】仿 DeskToDo TaskDialog：名称 + 优先级(白/橙/绿/红) + 重复(单次/范围每天/范围内每周几/指定多日) + 起止时间 + 地点 + 备注 + 提醒提前N分钟；默认只在当日新增。
- **单击任务条** → 信息小卡片：显示起止/截止时间 + 名称 + 简介（上版已做，保留）。

## 三、农历/节假日（已确认）
- **农历数据源**：仿 DesktopCal —— 用成熟库预生成每年农历 json 打包到本地，运行时查表解析（不是运行时实时算，不引入大依赖）。
- **农历显示范围**：含宜忌黄历，且**可手动开关**（仿 DesktopCal `ShowJiYi` 等显示项开关）。
- **校历周次**：周数按校历看 —— 提前把校历解析成 json 存本地，显示时按校历周次（不是简单年内第几周）。**校历未导入阶段回退自然周**：在还没有校历 json 时，按 DesktopCal 的周划分（ISO 自然周，周一起始）；一旦导入校历，**有校历周则用校历周，没有校历周的日子回退自然周**。
- **周数显示**：月视图左侧「第N周」列 + 周视图头部「YYYY年M月 第N周」（自然周号；有校历周则显示校历周）。

## 四、【日历-设置】面板（已确认）
- **入口**：托盘右键菜单加【日历设置】→ 点击跳转设置面板；同时桌历窗口内也放设置入口（齿轮）。
- **tab/设置项**（仿 DesktopCal 成熟设置项，可多选 → 实际全做）：
  - 显示项开关：节假日 / 节日 / 农历 / 24节气 / 宜忌黄历 / 周数（各可开可关）。
  - 外观：玻璃开关 + 背景色 + 透明度。
  - 颜色：日历/单元格/今天边框/农历/节假日 文字颜色（仿 DesktopCal FontColor）。
  - 开机自启。
- **事件线样式设置**：跟随主界面（色条/圆点两档），主界面已有 eventStyle。

## 五、替换（已确认）
- 用新版 Electron 桌历**替换旧 DeskToDo**（去掉 spawn Python 进程）。

## 六、后续问答确认（已全部确认，落盘）
1. **主题**：桌历**自己可切主题**（设置里选浅/深/高对比），不强制跟随主界面。
2. **新增事件写入**：**写入正式 schedule 任务库**（主界面【日程】也能看到该新事件）。
3. **设置持久化**：**持久化**（重启后保留设置，存本地 json/sqlite）。
4. **无时间事件**：双击新增**可不填时间** → 作为"无日期待办(floating)"，显示在主界面/桌历的**"无日期待办"条区**，**不进日历格子**（与主界面一致）。
5. **双击交互**：**双击事件条 → 编辑该事件**；**双击空白格子 → 新增那天的事件**（日期默认那天）。
6. **新增默认值**：名称必填，优先级默认白，重复默认单次，时间可选（可留空成无日期待办，默认当天时间段）。
7. **设置存储**：用 CampusOS 已有 **sqlite**（settings/桌历表）。
8. **入口**：托盘菜单加【日历设置】+ 窗口内右上角齿轮，**两个都做**。
9. **周/日视图**：照搬主界面 `schedule-week-grid`（7列）/ `schedule-day-timeline`（时间线）。
10. **窗口尺寸**：仿 DesktopCal/DeskToDo——默认中/大，用户**可拖边+右下角缩放**，格子随窗口自适应，尺寸按显示器签名记忆。
11. **事件线样式**：跟随主界面（色条/圆点两档）。
12. **设置面板 tab**（仿 DesktopCal/DeskToDo）：显示项开关(节假日/节日/农历/24节气/宜忌黄历/周数) · 外观(玻璃开关+背景色+透明度) · 颜色(日历/单元格/今天边框/农历/节假日文字色) · 开机自启。

## 七、第二轮 DesktopCal 细读新增确认（补齐没落盘的点）
13. **窗口外观**：**背景毛玻璃/高斯模糊**（DesktopCal `blurBkgnd`，之前误判"无毛玻璃"）+ Win11 DWM 圆角(`dwmWindowCorner`) + 窗口阴影(`useWindowShadow`+shadowImage)。用户已选**要毛玻璃**。
14. **置顶切换**：需要**"置顶/不置顶"切换按钮**（默认贴底，可临时置顶）。
15. **图钉 StapleButton**：**需要**——默认窗口可移动；**钉上图钉=锁定位置/大小**（调整位置/大小都由图钉控制），要移动调整就取下图钉（免去进设置页）。
16. **贴边吸附**：**不需要**（拖到边缘自由停，不吸边）。
17. **事件额外字段**（仿 DesktopCal）：**重复次数/结束条件**（无限/自定义次数/按周几）· **通知提前时/天**（含分钟）· **事件标记完成/已读** · **事件文字颜色**。
18. **提醒提前单位**：**分钟+时+天都可**。
19. **课表展示**：**今天有课高亮**(`9GridEleLessonToday`) + 格子只显示课程名（事件条）· **单击课程→小卡片**显示 节次/时间/教师/地点。
20. **微信通知**：**不做**（DesktopCal 靠扫码公众号+云端服务端推送，CampusOS 无云端，暂不做；应用内提醒已够）。
21. **多语言**：只要**中文**（不需要 i18n）。
22. **工具栏按钮**：仅【搜索】；不需要 收藏/分享（图钉已单独说明）。
23. **校历周次显示**：只在**今天/选中时**显示周次（不在日历侧栏常驻）。
24. **格子右键**：**不需要右键菜单**——只用 双击新增/编辑 + 单击信息卡片（已定）。
25. **已完成事件样式**：**灰显/删除线**（跟随主界面 `schedule-event.is-complete`）——已勾完成的事件条灰显。
26. **导入导出**：**不需要**（CampusOS 主界面已有导出 iCal/MD/图片）。
27. **窗口外观毛玻璃确认**：背景毛玻璃(blurBkgnd) 已定要；DWM 圆角/阴影作为窗口外观一并实现（可选看效果）。

## 九、明确排除项（不实现，避免未来误加）
- **微信/公众号通知推送**：DesktopCal 依赖扫码公众号 + 云端服务端推送；CampusOS 本地优先、无云端，不做（应用内提醒已够）。
- **在线桌面管理/下载市场（dskmgr）**：在线下载额外小部件/皮肤市场，非本地桌历核心，不做。
- **在线壁纸皮肤市场( wp )**：VIP/免费壁纸合集市场，非本地桌历核心，不做。
- **账号注册/扫码登录（login）**：在线账号体系，不做。
- **会员/VIP 升级与权益墙（vip）**：在线付费，不做。
- **贴边吸附**：拖到屏幕边缘自动吸附 —— 不要（拖到边缘自由停）。
- **多语言 i18n**：只要中文。
- **导入/导出**：主界面已有（导出 iCal/MD/图片），桌历不重复做。
- **事件线样式多档**：只做主界面已有的 色条/圆点 两档（不做 DesktopCal 的无/数字/圆点多档）。
- **日历格子右键菜单**：只用 双击新增/编辑 + 单击信息卡片，不做右键菜单。
