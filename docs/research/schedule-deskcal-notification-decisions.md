## 一、日程页（ScheduleView）—— 12 项决议

1. **月视图溢出**：事件超过 N 条 → 前 N 条 + 「+N 更多」按钮 → 当天事件 popover（FullCalendar 式）。
2. **创建方式**：周/日视图点击空档直接弹创建气泡（预填起止时间）；月视图双击格子创建。
3. **拖拽编辑**：全量拖拽——移动 + 边缘缩放 + 15/30 分钟网格吸附 + 落点冲突提示（DayPilot/Cal.com 式）。
4. **当前时间线**：周/日时间轴红色当前时间指示线，随分钟实时移动。
5. **日期导航**：日期跳转控件 + 周起始日可设（默认周一）+ 键盘方向键翻页 + 侧栏迷你月历联动。
6. **时间粒度**：默认 30 分钟一格，设置可切 15 分钟。
7. **非工作时段**：默认折叠深夜（0:00–7:00、22:00–24:00），可展开。
8. **事件颜色**：课程/任务/截止/考试/日程各一固定语义色，进 design token；支持按类型筛选。
9. **任务与日历融合（已被后续决策更新）**：所有本地任务都有开始和结束时间并进入日历；不再提供 `floating` 无日期待办。
10. **侧栏结构**：迷你月历 + 类型开关 + 周数/校历信息。
11. **密度与深色**：月视图「色条/圆点」双呈现切换 + 舒适/紧凑两档密度；深色模式跟随系统。
12. **自然语言创建**：新建框支持自然语言（如「下周三 14:00 数据库答疑 1 小时」），复用 AI 助手抽取管线。

## 二、桌面日历（悬浮窗）—— 5 项决议 + 1 项待定

1. **事件呈现**：月/周/日格子事件为彩色小条+短标题（与主日程同语义色体系）；悬停看详情；点击跳主日程对应日期。
2. **联动**：点击悬浮窗事件 → 打开主窗口并定位到该事件对应日期+详情（复用导航链路）。
3. **布局**：默认月视图 + 下方当日议程条（月历上方 + 当天几件事一览）；时钟/天气/倒计时等组件保留可开关。
4. **导航**：翻月（左右箭头）+ 点日期选日 + 今日高亮；滚轮在月/周/日视图间切换；拖拽移动/边缘调尺寸保留。
5. **外观（d6 待定项已定）**：毛玻璃背景 + 透明度滑块 + 多套独立配色主题（与主应用主题独立）；时钟/天气/倒计时保留可开关。
6. **视觉风格（d4）**：浅色主+深色跟随系统，克制配色（现有 paper/ink 品牌体系），毛玻璃只用于悬浮层；**具体样式待功能实现后截图迭代确认**。

## 三、调休/补课日历（f13 展开）—— 8 项决议

1. **数据来源**：内置校历（节假日+补课安排）+ 用户手动校正（错误可改）。
2. **补课展示**：补课日醒目标记（「补周一课」标签/描边）+ 把被补那天的实际课程排入该日格子。
3. **节假日展示**：节假日背景弱化 + 显示节日名；**默认不排课，但周末是否有课以校历+实际抓取数据为准**（部分周末有特殊教学项目）；节假日确有课由学生手动录入。
4. **首页调休卡片**：首页**下部**位置，配色显眼但仅作提醒，**不侵占首页主功能**；显示本周哪天放假/哪天补课补周几/课表是否受影响（一句话）；点击展开详情或跳日历；无调休周不显示。
5. **周末排课判定**：周末格子照常显示抓到的排课；无课按普通周末；节假日即使抓到课也默认不排（除非手动录入）。
6. **手动录入入口**：日历格右键/长按某天 → 「设为节假日」「设为补课（选补周几的课）」；首页卡片也可进入调整。
7. **首页卡片内容**：本周概览（放假/补课/受影响）+ 点击跳日历；仅本周有调休时出现。
8. **同步范围**：补课标记主日程与桌面日历悬浮窗同步显示（两处一致）。

## 四、通知中心 —— 14 项决议

1. **点击位移**：删除铃铛按钮与通知条目的按下位移 → 改为 hover/active 背景变色（或涟漪）；位移只保留给有物理按键感的按钮。
2. **点击条目**：跳转到对应目标（日程/资料/学业/设置等）+ 标记已读；**已读走真实持久化（IPC）**，不是前端假装；无跳转目标的通知只标记已读；带明确目标的通知显示跳转箭头。
3. **未读指示**：未读条目左侧色条/圆点 + 背景加重；铃铛显示未读数字徽标（上限 99+）。
4. **筛选与批量**：全部/未读/已读筛选 + 「全部已读」按钮 + 单条已读/未读切换。
5. **过期与容量**：通知不提供硬删除操作；用户手动收起改为 `handled`，系统按保留策略标记 `expired`。最多保留最近 500 条，超限时优先保护未读通知。
6. **时间显示**：相对时间（x 分钟前/x 小时前/昨天/x 天前）+ 悬停显示精确时间；运行时计算不写死。
7. **跳转边界**：有目标就跳，无目标只已读。
8. **多选批量**：多选模式：勾选多条 → 批量已读/标记已处理（GitHub 收件箱思路）。
9. **来源整合**：统一通知中心接收系统、学业、校园资讯与日程提醒；下载完成属于一次性 toast + 自定义音效，不写入通知中心。
10. **校园资讯归属**：资讯正文和未读状态仍以 campus-feed 的 SQLite 记录为准；通知中心只保存可回看的轻量引用（来源、标题、摘要、条目 id、批次 id），不复制正文。
11. **通知持久化（2026-09-06）**：通知内容与状态使用同一 SQLite 的 migration 13；旧 notifications.json 仅一次导入。同步事务提交先于系统提示，备份中的任务和通知共同提交或回滚，保留外部备份格式兼容性。
11. **资讯预览与处理**：同一来源同一轮刷新按批次折叠；展开条目即标记已读，在面板内先看摘要；“查看详情”定位到校园资讯对应条目并标记 `handled`，“忽略”只标记 `handled`，不删除资讯原记录。
12. **首次同步**：每个资讯源首次成功同步只建立持久化基线，不制造历史通知；以后新增或内容变化才进入通知中心。一轮刷新只发一条聚合系统 toast，中心内仍保留逐条引用。
13. **提醒补发**：日程提醒在实际触发时写入通知中心；应用启动时补收最近 24 小时内错过的提醒，并以提醒实例 id 去重，超过 24 小时不补发。
14. **原生通知点击**：点击系统 toast 恢复并前置 CampusOS，跳到对应模块/条目，同时把该条通知标记已读。

## 五、视觉基调（d4/d6/v 系列）—— 4 项决议

1. 浅色为主、深色跟随系统；配色从现有品牌色推导（paper/ink），避免模板感渐变；毛玻璃只用于悬浮层。
2. 月视图默认色条+短标题，提供圆点模式切换；舒适/紧凑两档密度。
3. 桌面日历悬浮窗：毛玻璃+透明度滑块+独立主题。
4. 验收流程：先做可用版本 → 用户本地运行/截图 → 按 ai-frontend-lessons 逐条过（无意义框/重叠/溢出/间距/平衡）→ 迭代到满意。

## 六、实施顺序（按风险从低到高）

1. **通知中心**：位移删除 + hover/涟漪 → 未读指示/筛选/全部已读/单条切换 → 相对时间 → 多选批量 → 过期清理 → 多来源整合与点击跳转。
2. **日程核心交互**：+N more popover → 点击/双击创建 → 当前时间线 → 拖拽（移动/缩放/吸附/冲突提示）→ 导航（跳转/周起始日/方向键/迷你月历）→ 粒度/折叠 → 语义色+筛选。
3. **调休/补课校历**：数据模型与内置校历 → 手动录入（右键）→ 补课排课入格 → 节假日弱化 → 首页卡片 → 桌面日历同步。
4. **任务与日历融合**：侧栏待办区 → 任务进日历格 → 拖拽改期。
5. **桌面日历**：事件色条+短标题 → 点击跳主窗口 → 月+当日议程布局 → 滚轮切换 → 毛玻璃/透明度/主题。
6. **视觉打磨**：深色模式 → 密度档位 → 色条/圆点切换 → 首页/桌面日历视觉迭代。
7. **#7 零学分课程**：对照 Celechron → 修 xkkh 合并 → 0 学分标记 → 真实基线验收。
