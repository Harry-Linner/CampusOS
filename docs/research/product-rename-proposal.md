# 产品改名提案（CampusOS → 新名）

**日期:** 2026-08-25
**状态:** 提案（待用户挑选/确认后执行仓库级改名）
**背景:** 市面上已存在多个同名 "CampusOS" 产品（[Devpost CampusOS 项目](https://devpost.com/software/campusos-9khcmf)、[Trae 论坛"AI 校园成长操作系统 CampusOS"](https://forum.trae.cn/t/topic/72386)、[CampusOS Pitch Deck](https://prezi.com/p/qdacown42ie_/campusos-pitch-deck/) 等），用户决定改名。
**改名范围（确认后执行）:** 仓库目录/包名建议保持不变（`@campusos/*` 是内部标识，避免破坏插件安装记录与能力 provenance），改名落到**用户可见层**：产品显示名、README/PRD/plan/research 标题、窗口标题、托盘名、安装包名、About/设置页展示名。

---

## 一、命名约束（来自产品定位）

1. **面向学生**：ZJU 本科为主，未来扩展其他高校 → 名字不应绑定"浙大"（求是/启真/紫金 等排除或仅作副名）。
2. **桌面校园工作台**：VS Code 式插件化工作台，统一课表/教务/课件/提醒 → "工作台/聚合/桌面"心智有价值。
3. **AI 助手**：产品内有 AI 助手（学业问答/日程提取）→ 名字最好不排斥 AI 扩展。
4. **可注册**：避免与现有产品撞名（已实测排除：知序、StudyDesk；CampusOS 本身）。
5. **中英皆可**：面向中文用户，但英文名便于包名/社区/国际化。

## 二、候选名单（按风格分组）

### 组 A：延续"校园工作台"心智（推荐首选）
| 候选 | 英文/拼音 | 理由 | 冲突检查 |
|---|---|---|---|
| **校园台** | CampusDeck | "Deck"= 甲板/工作台，呼应 VS Code 式插件工作台；与 DeskTop 区分 | 需进一步核查 |
| **学序** | LearnOS / XueXu | 学习+秩序（课表=秩序感），中文简洁；"OS" 延续插件化心智 | 未见明显冲突 |
| **科序** | KeXu | "科"= 科目/科学，"序"= 课程秩序；比"学序"更理科向 | 未见明显冲突 |
| **课台** | KeTai | 课表+工作台，直白好记 | 未见明显冲突 |

### 组 B：时间/日程意象（突出"统一日程"核心）
| 候选 | 英文/拼音 | 理由 | 冲突检查 |
|---|---|---|---|
| **校历** | SchoolCal | 直白，但过于通用，搜索噪音大 | 通用词，易撞 |
| **课间** | Kejian / Interval | 场景感（课间查看），有记忆点 | 需进一步核查 |
| **晨课台** | MorningDeck | 早晨看课表/日程的场景 | 未见明显冲突 |

### 组 C：英文创意名（包名友好）
| 候选 | 理由 | 冲突检查 |
|---|---|---|
| **Camplus** | Campus + plus，短、好记、校园强绑定 | 未检索到明显同名产品（仍需注册前核查） |
| **CampusHub** | "中枢/统一入口"心智，直白 | 需进一步核查 |
| **StudyDeck** | Study + Deck（工作台），避免 StudyDesk 撞名 | 与 study-desk 区分度高 |
| **CampusOS**（现名） | 保留 | 已确认撞名，需换 |

### 组 D：AI 助手方向（长期扩展）
| 候选 | 理由 | 冲突检查 |
|---|---|---|
| **小序** | "学序"的拟人化，契合 AI 助手交互面 | 未见明显冲突 |
| **Astra / 学伴** | 学习伙伴心智 | 通用词，可能撞 |

## 三、推荐方案

**首选组合：英文 `CampusHub`（或 `Camplus`）+ 中文「校园台」（或「学序」）**

- 理由：CampusHub 保留"校园"辨识度、去掉已撞名的 OS 后缀，Hub（中枢）准确表达"统一入口"定位；中文「校园台」直白好记，兼顾未来扩展其他高校。
- 备选：如果更想强调"学生/学习"，用 **StudyDeck + 「学序」**；如果更想突出 AI 助手，用 **Camplus + 「小序」**。

## 四、确认后执行清单（本提案不执行代码变更）

1. `packages/core/src/main/main.ts`：窗口标题、托盘 tooltip 的显示名。
2. `README.md` / `PRD.md` / `plan.md` / `research.md` / `docs/compliance-analysis.md` 标题与正文产品名。
3. 安装包 productName（electron-builder 配置，若存在）与 About 页。
4. 内部 `@campusos/*` 包名与能力 ID **保持不变**（避免破坏插件安装/能力 provenance/已存数据）。
5. 仓库目录名 CampusOS 可保留为内部代号，或一并改名（需评估 git 历史影响，建议保留）。
