# 产品改名候选（归档 · 结论=不改名）

> **状态:** 已归档（2026-08-29）。**用户最终拍板：不改名，沿用 CampusOS**（08-27 原话「算了，就这个名字了，不改了，反正我这软件受众比较集中」）。
> **完整候选与命名约束见：** [`docs/research/product-rename-proposal.md`](./product-rename-proposal.md)（本文件仅作归档索引，不重复正文）。
> **背景:** 因市面上已存在多个同名 "CampusOS" 产品（Devpost CampusOS 项目、Trae 论坛帖子、Pitch Deck 等），曾调研改名；后因受众集中、改名收益有限而放弃。

## 一、调研结论速览

- **为什么想改**：与社区同名产品撞名，可能造成混淆。
- **调研结论**：候选含 4 组（校园工作台 / 时间日程 / 英文创意 / AI 助手），推荐 `CampusHub`/`Camplus` + 「校园台」/「学序」；撞名检查部分候选需注册前进一步核查。
- **用户最终决定**：**不改名**。理由：受众集中、改名收益有限；改名只改用户可见层（显示名/文档标题/窗口/托盘/包名），内部 `@campusos/*` 包名与能力 ID 保持不变（避免破坏插件安装/能力 provenance/已存数据）。

## 二、如未来再议改名（备忘）

1. 只改**用户可见层**：产品显示名、README/PRD/plan/research 标题、窗口标题、托盘名、安装包名、About/设置页展示名。
2. 内部 `@campusos/*` 包名与能力 ID **保持不变**。
3. 仓库目录名 CampusOS 可保留为内部代号。
4. 需重新做撞名核查（覆盖 GitHub/npm/应用商店）。
